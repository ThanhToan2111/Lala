# ConFu++ v6.0 paper package

The paper package is organized by scientific question rather than development version.

- `theory/`: population projection proposition, assumptions, and proof notes.
- `related_work_matrix.md`: primary-source positioning audit.
- `claims.md`: evidence/limitation/status matrix.
- `reviewer_questions.md`: prepared responses to predictable objections.
- `scripts/`: reproducible conceptual figures and result tables.
- `draft/`: v6.1 skeleton, Abstract v1, and Introduction v1 built from the frozen evidence.

The v6.1 calibration-only confirmation is preregistered at `results/calibration/v61/C1_PROTOCOL.md` and reported at `results/calibration/v61/C1_MOSEI_NULL_REPORT.md`.

All empirical numbers must be regenerated from JSON artifacts under `results/`; no manual table transcription is permitted.
